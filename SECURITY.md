# Security

## Reporting a vulnerability

Please report security issues privately to **security@njordium.com** rather than opening a public issue.

We aim to acknowledge reports within 3 working days and provide a remediation timeline within 10 working days.

## Status

This app is at v0.0.1 (initial scaffold). A full security posture document — OAuth flow specifics, token storage, OWASP Top 10 mapping — will be published once the Inspect360 API integration is wired up. Until then the OAuth and token-storage scaffolding follows the pattern established in [`integration_forgejo_gitea`](https://github.com/njordium/integration_forgejo_gitea/blob/main/SECURITY.md).
